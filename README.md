# Wodby boilerplates

Wodby boilerplates are ready-to-use starter projects for popular application
frameworks. When you create a project, Wodby can import the selected
boilerplate into a new GitHub or GitLab repository so you can start with a
working application instead of an empty repository.

Choose the boilerplate that matches your application. After Wodby imports it,
the new repository is yours to customize and develop normally.

## Standalone inference examples

[LLM inference client](https://github.com/wodby/llm-inference-boilerplate) provides
dependency-free Python examples for ordinary and streaming chat completions
against an existing OpenAI-compatible endpoint, including the
[vLLM stack](https://github.com/wodby/stack-vllm).

Run it from a machine that can reach the private endpoint. It does not deploy a
model server and is not a selectable application-build boilerplate.

The boilerplates available to you depend on the service selected for your
application. Learn more in the [Wodby CI/CD documentation](https://wodby.com/docs/2.0/cicd/).
