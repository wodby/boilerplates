# Wodby boilerplates

Wodby boilerplates are ready-to-use starter projects for popular application
frameworks. When you create a project, Wodby can import the selected
boilerplate into a new GitHub or GitLab repository so you can start with a
working application instead of an empty repository.

Choose the boilerplate that matches your application. After Wodby imports it,
the new repository is yours to customize and develop normally.

## Available boilerplates

| Boilerplate | Best for |
| --- | --- |
| [Django](https://github.com/wodby/django-boilerplate) | Python applications built with Django |
| [Drupal CMS](https://github.com/wodby/drupal-cms-template) | New Drupal CMS projects |
| [Vanilla Drupal](https://github.com/wodby/drupal-vanilla) | Standard Drupal projects |
| [Express.js](https://github.com/wodby/expressjs-boilerplate) | Node.js APIs and web applications built with Express |
| [FastAPI](https://github.com/wodby/fastapi-boilerplate) | Python APIs built with FastAPI |
| [Flask](https://github.com/wodby/flask-boilerplate) | Python web applications built with Flask |
| [Go](https://github.com/wodby/go-boilerplate) | Go web applications and APIs |
| [Next.js](https://github.com/wodby/nextjs-boilerplate) | Full-stack React applications built with Next.js |
| [Composer package](https://github.com/wodby/php-package-boilerplate) | PHP packages managed with Composer |
| [Python](https://github.com/wodby/python-boilerplate) | General Python applications |
| [Rails](https://github.com/wodby/rails-boilerplate) | Ruby applications built with Rails |
| [React](https://github.com/wodby/react-boilerplate) | Client-side React applications |
| [Ruby](https://github.com/wodby/ruby-boilerplate) | General Ruby applications |
| [Vanilla WordPress](https://github.com/wodby/wordpress-vanilla) | Composer-based WordPress projects |

## Upstream templates

Wodby also supports starter projects maintained by their upstream communities:

| Template | Best for |
| --- | --- |
| [Laravel](https://github.com/laravel/laravel) | PHP applications built with Laravel |
| [Matomo](https://github.com/matomo-org/matomo) | Self-hosted Matomo analytics projects |

The templates available to you depend on the service selected for your
application. Learn more in the [Wodby CI/CD documentation](https://wodby.com/docs/2.0/cicd/).
